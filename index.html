hibr apt repository

Debian and Ubuntu packages of hibr, a small, fast shell that runs the bash you already write.

Install

curl -fsSL https://osakka.github.io/hibr-apt/hibr.gpg \
  | sudo tee /usr/share/keyrings/hibr.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/hibr.gpg] https://osakka.github.io/hibr-apt stable main" \
  | sudo tee /etc/apt/sources.list.d/hibr.list
sudo apt update
sudo apt install hibr

apt upgrade keeps it current. Then man hibr, or start with From bash to hibr, in ten minutes.

What there is

architecturesamd64 (arm64 to follow)
needsglibc 2.34 or later: Debian 12, Ubuntu 22.04, or newer
installs/usr/bin/hibr, modules in /usr/lib/hibr, man hibr, the text desktop
